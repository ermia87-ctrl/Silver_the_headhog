# Sonic 1 Persian Edition — Android

نسخهٔ اندرویدی فارسی برای اجرای Sonic the Hedgehog نسخهٔ Genesis / Mega Drive (1991) با ROM انتخاب‌شده توسط کاربر.

## رابط و تصویرها
- صفحهٔ آغاز فارسی با تصویر برداری اختصاصی از تپه‌های سبز و حلقه‌های طلایی
- حفظ آیکون کلاسیک سونیک در لانچر اندروید
- دکمهٔ انتخاب ROM با پشتیبانی از ZIP، MD، BIN و GEN
- حالت افقی و کنترل لمسی موتور شبیه‌ساز

## ترجمهٔ داخل بازی
- نوشتهٔ صفحهٔ شروع و برچسب‌های HUD در داده‌های گرافیکی ROM جایگزین شده‌اند.
- «تیم سونیک تقدیم می‌کند»، «دوباره تلاش کن» و منوی انتخاب مرحله هنوز به‌صورت کامل به گرافیک و نقشه‌های ROM متصل نشده‌اند.
- تا زمان تکمیل و آزمایش این سه بخش، این خروجی پیش‌نمایش است و نسخهٔ نهایی محسوب نمی‌شود.

## اجرا
1. APK پیش‌نمایش را نصب کن.
2. اینترنت را روشن کن؛ موتور شبیه‌ساز در این نسخه از CDN بارگیری می‌شود.
3. «انتخاب فایل بازی» را بزن و ZIP یا ROM مجاز خودت را انتخاب کن.

فایل ROM داخل مخزن عمومی منتشر نمی‌شود؛ فرایند ساخت از فایل بازی موجود در شاخهٔ خصوصی/مجاز پروژه استفاده می‌کند.

## Build
GitHub Actions با Java 17، Android SDK و Gradle 8.9 فایل APK پیش‌نمایش می‌سازد.
