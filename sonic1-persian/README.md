# Sonic 1 Persian Edition — Android

پروژه برای ساخت یک نسخهٔ اندرویدی فارسی بر پایهٔ **Sonic the Hedgehog کلاسیک (Genesis / Mega Drive، سال ۱۹۹۱)**.

## وضعیت فعلی

- ساختار پروژهٔ اندروید و گردش‌کار ساخت خودکار APK در GitHub Actions ایجاد شده است.
- یک نمونهٔ آزمایشی دوبعدی با کنترل لمسی، پرش و حلقه‌ها در کد قرار دارد.
- این نمونه **بازی اصلی Sonic 1 نیست** و فعلاً شخصیت‌ها، مراحل، موسیقی و گرافیک اصلی را ندارد.
- هیچ ROM یا فایل دارای حق نشر در این مخزن قرار داده نشده است.
- ساخت APK هنوز باید در GitHub Actions با موفقیت تمام شود.

## مسیر فنی درست

این پروژه هدفش نسخهٔ ۱۹۹۱ کنسول Genesis است. پروژه‌های بازسازی Retro Engine برای نسخهٔ ۲۰۱۳، جایگزین مستقیم نسخهٔ ۱۹۹۱ نیستند و داده‌های بازی متفاوتی می‌خواهند.

برای رسیدن به نسخهٔ موردنظر باید:
1. مسیر اجرای سازگار با بازی Genesis در اندروید انتخاب و یکپارچه شود.
2. فایل بازی فقط از نسخه‌ای که کاربر قانوناً در اختیار دارد، در دستگاه خودش بارگذاری شود؛ فایل بازی در مخزن یا APK منتشر نمی‌شود.
3. رابط فارسی، منوها و کنترل‌های لمسی پیاده‌سازی شوند.
4. شخصیت‌های اضافه با کد و دارایی‌هایی که اجازهٔ استفاده از آن‌ها وجود دارد ساخته شوند.
5. عملکرد و پایداری روی گوشی‌های اندرویدی، از جمله دستگاه‌های میان‌رده، آزمایش شود.

## ساخت

گردش‌کار GitHub Actions با هر تغییر در این پوشه اجرا می‌شود و در صورت موفقیت، APK آزمایشی را به‌عنوان Artifact بارگذاری می‌کند.

## مجوز و دارایی‌ها

کدهای پروژه و دارایی‌های بازی باید مجوز روشن و سازگار داشته باشند. ROM، موسیقی، تصاویر و سایر داده‌های دارای حق نشر بدون مجوز در مخزن قرار نمی‌گیرند.
