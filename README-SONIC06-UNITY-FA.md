# پروژهٔ سه‌بعدی فارسی — Unity / Android

این شاخه یک پایهٔ توسعهٔ مستقل برای بازی سه‌بعدی اکشن/دونده با الهام کلی از پلتفرمرهای سه‌بعدی سرعتی است. این پروژه بازسازی رسمی Sonic the Hedgehog (2006) یا محصول SEGA نیست.

## وضعیت فعلی
- کدنویسی Unity 6 با C#
- کنترل لمسی کشیدن انگشت برای تغییر مسیر و پرش
- حرکت رو به جلو، پرش، جمع‌آوری حلقه‌های امتیازی و موانع
- دوربین تعقیب‌کننده
- HUD فارسی
- ابزار Editor برای ساخت صحنهٔ آزمایشی از primitiveهای Unity
- فهرست جایگاه شخصیت‌ها؛ مدل‌ها و انیمیشن‌های مجاز باید جداگانه اضافه شوند

## ساخت صحنهٔ آزمایشی
1. Unity Hub و نسخهٔ Unity 6 همراه Android Build Support را نصب کن.
2. این پوشه را به‌عنوان پروژه باز کن.
3. از منوی Tools > Persian Runner > Create Demo Scene صحنهٔ آزمایشی را بساز.
4. صحنهٔ Assets/Scenes/Demo.unity را باز و Play کن.

## خروجی Android
در Build Profiles پلتفرم Android را انتخاب کن، معماری ARM64 را فعال کن و صحنهٔ Demo را به فهرست صحنه‌ها اضافه کن.

## دارایی‌ها و مالکیت فکری
مدل‌ها، صداها، لوگوها و شخصیت‌های فیلم Sonic متعلق به صاحبان حقوق مربوط‌اند. این مخزن آن دارایی‌ها را شامل نمی‌شود. فقط از فایل‌هایی استفاده کن که مجوز روشن برای استفاده و توزیع آن‌ها داری. جایگاه‌های roster را می‌توانی به مدل‌های دارای مجوز متصل کنی.

## هدف حجم
حجم ۳۰۰ مگابایت هدف انتشار است، نه چیزی که با فایل‌های ساختگی ایجاد شود. حجم واقعی باید از مراحل، مدل‌ها، بافت‌ها و صداهای واقعی و دارای مجوز حاصل شود. فعلاً APK ساخته نشده و این شاخه فقط سورس پروژه است.
