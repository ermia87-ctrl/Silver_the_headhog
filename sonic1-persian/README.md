# Sonic 1 Persian Edition — Android

نسخهٔ اندرویدی فارسی برای اجرای Sonic the Hedgehog نسخهٔ Genesis / Mega Drive (1991) با ROM انتخاب‌شده توسط کاربر.

## امکانات فعلی
- رابط فارسی و حالت افقی اندروید
- انتخاب فایل ROM از حافظه
- استخراج خودکار فایل MD/BIN/GEN از ZIP
- اجرای بازی با موتور EmulatorJS و هستهٔ Sega Mega Drive
- کنترل لمسی توسط رابط موتور شبیه‌ساز

## اجرا
1. APK را نصب کن.
2. اینترنت را روشن کن؛ موتور شبیه‌ساز در این نسخه از CDN بارگیری می‌شود.
3. «انتخاب فایل بازی» را بزن و ZIP یا ROM مجاز خودت را انتخاب کن.

فایل ROM داخل APK یا مخزن قرار داده نمی‌شود. این نسخه بازی اصلی را با شبیه‌سازی اجرا می‌کند؛ بازسازی مستقل گرافیک، تغییر شخصیت‌ها و ترجمهٔ نوشته‌های داخل خود بازی هنوز انجام نشده است.

## Build
GitHub Actions با Java 17 و Gradle 8.9 فایل APK آزمایشی می‌سازد.
