# Sonic 1 Persian Edition

پروژه‌ی اندرویدی برای ساخت نسخه‌ی فارسی Sonic the Hedgehog (Genesis / Mega Drive, 1991).

## وضعیت فعلی
این فقط اسکلت اولیه‌ی اپ اندروید است؛ هنوز موتور اجرای بازی، داده‌های بازی یا ROM اضافه نشده و APK فعلی بازی کامل نیست.

## مراحل بعدی
1. افزودن هسته‌ی سازگار با Genesis.
2. رابط فارسی راست‌به‌چپ و کنترل لمسی.
3. افزودن شخصیت‌های جدید با دارایی‌های مجاز.
4. ساخت و آزمایش APK در GitHub Actions.

فایل ROM، موسیقی و گرافیک دارای حق نشر بدون مجوز در مخزن قرار نمی‌گیرند.
